This project is a redesign of the Features page for HelloBookkeeping, an AI-powered accounting platform. The assignment was provided as part of a UI/UX challenge by the company, with the goal of improving the visual hierarchy, user experience, and responsiveness of their existing website. The redesigned page focuses on showcasing the top features of the product in a clean and modern layout that supports both desktop and mobile users. Key improvements include a simplified structure, clear sectioning of content, responsive card layouts, and the use of a “View More Features” toggle to reduce visual clutter. The design is implemented using HTML, Tailwind CSS, and vanilla JavaScript, with a strong emphasis on accessibility and brand consistency. This project demonstrates practical application of modern design principles in a real-world business context, and serves as both a functional prototype and a potential production-ready component for the company's marketing site.
